# Bolder

A 2D platformer (codename Bolder).

**Install:** download [Bolder-Setup.exe](installer/Bolder-Setup.exe) (or the zip next to it), run it and follow the wizard.
It is small: it downloads the game from this repository, checks every file's SHA-256 and installs it for your user
account (no administrator rights). The game checks for updates at start and asks "Update now / Later"; the update downloads inside the game and it restarts by itself.

This repository only holds the latest released game files. Windows may warn "unknown publisher" (the setup is not code-signed).
